# 【星宇・探索】互動式宇宙科普平台 (Interactive Space Explorer) 🌌

### 🎯 開發背景
本專案靈感源於高中**地球科學**課程。我發現課本知識雖豐富，但缺乏直觀且美觀的互動平台。因此，我決定開發這款工具，將複雜的天文數據轉化為互動體驗，協助學習者更高效地探索宇宙。

### 📖 專案簡介
本專案是一個基於原生 Web 技術開發的互動式天文科普平台。使用者可以透過直觀的介面探索太陽系、仙女座星系，並查詢黃道十二宮的相關資訊。本作品旨在將抽象的天文數據轉化為具備美感與互動性的數位體驗。

### 🛠️ 技術棧 (Tech Stack)
* **前端開發**：HTML5, CSS3, JavaScript (Vanilla JS)
* **介面設計**：獨立完成 UI/UX 設計，實作深色模式 (Dark Mode) 與多層次佈局
* **開發工具**：VS Code, Git, AI 輔助開發 (Gemini / ChatGPT)

### 🤖 AI 協作開發聲明 (AI-Augmented Development)
在本專案中，我實踐了「人機協作」的 **Vibe Coding** 流程：
* **邏輯優化**：運用 AI 協助生成星球運動的數學演算邏輯（如三角函數座標計算），並由人工進行數據調優與功能整合。
* **生產力提升**：藉由 AI 自動化生成大量重複元件（如 150 顆動態小行星），大幅縮短開發週期。
* **除錯與測試**：利用 AI 輔助進行 JS 邏輯除錯，確保在不同瀏覽器環境下的穩定性。

### 🌟 核心功能
* **星系跳轉系統**：實作太陽系與仙女座星系的動態導覽。
* **行星成員全覽**：彙整八大行星科學數據，以卡片式佈局呈現細節。
* **星座索引系統**：整合黃道十二宮資訊，提供直觀的圖像化索引。
* **即時太空動態**：結合動態消息欄位，展示天文新知。

### 📬 意見回饋
本專案旨在持續迭代。若您在探索過程中發現任何數據錯誤或有改進建議，歡迎透過網頁下方的聯絡方式與我聯繫，我將視其為珍貴的優化參考。
